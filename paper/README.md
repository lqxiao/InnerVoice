# Paper draft (AAAI-27 format)

- `main.tex` — the paper; `refs.bib`; `ReproducibilityChecklist.tex` (filled; `\input` at the end of main.tex).
- `aaai2027.sty` / `aaai2027.bst` — unmodified from the official AuthorKit27.zip (https://aaai.org/authorkit27/, linked from the
  AAAI-27 submission instructions). The style requires **pdfLaTeX**; compile with `pdflatex main && bibtex main && pdflatex main && pdflatex main`.
- `tables/*.tex` are GENERATED by `python paper/tools/build_tables.py` from `REPORT_PART2.md` tables (themselves generated from
  `results/**/summary_*.json`) and `results/rl/*/eval.jsonl`, `aime25_avg8_final.json`. Do not hand-edit numbers.
- `tools/exa_search.py` — Exa web search with a hard cap (120 requests ≈ $0.84; the user's budget stop is $10). Usage counter in `tools/exa_usage.json`.
- Red `[PLACEHOLDER: ...]` marks in the PDF = experiments/results not yet run (32k-budget eval, SFT re-run without the grad-ckpt bug,
  data examples appendix, real-TTS latency / user study, buffer-aware RL).
- Local check build without pdfLaTeX: tectonic (XeTeX) on a scratch copy of the style with `\RequirePDFTeX` commented out
  (`/tmp/paperbuild`); `main.pdf` here is that check build (9 pages, no overfull boxes).
